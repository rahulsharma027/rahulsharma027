# Technology logo sources

The technology strip embeds local copies of the following vector icons:

- Go, Python, Spring, Kubernetes, Docker, Jenkins, GraphQL, Grafana, React, and Linux: [Simple Icons v16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/16.0.0/LICENSE.md).
- Java and Amazon Web Services: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), distributed under the [MIT License](https://github.com/devicons/devicon/blob/v2.17.0/LICENSE).

Brand marks belong to their respective owners. Their appearance identifies technologies used in the profile; it does not indicate sponsorship or affiliation.

`scripts/build_tech_loadout.py` records the exact download URLs. The source icons are in `assets/logos/`, so the displayed strip makes no requests to an external image service.
